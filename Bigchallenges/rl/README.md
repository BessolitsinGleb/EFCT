# Обучаемый агент ЭДКТ

Агент выбирает ячейку для контейнера среди 8 лучших по формуле и учится на последствиях
(перестановки при выдаче, отказы, стоимость операций). Обучение — PPO с маской действий.
**Данные синтетические** (имитационная модель площадки): это демонстрация функциональности;
при сотрудничестве с терминалом агент дообучается на его реальных данных.

| Файл | Что делает |
|---|---|
| `app/placement.py` | правила площадки, штабелирование, формула оценки, тариф — общие для программы и обучения |
| `app/agent/reward.py` | **функция награды — пишет автор** |
| `app/agent/features.py` | признаки ячеек-кандидатов (одинаковые при обучении и в программе) |
| `app/agent/policy.py` | обученная сеть на numpy — так агент работает в программе без torch |
| `rl/yard_sim.py` | имитационная модель: поток контейнеров, выдачи, перестановки |
| `rl/env.py` | среда Gymnasium: наблюдение, маска действий, награда |
| `rl/tune_formula.py` | формула v2: подбор весов формулы (Optuna) |
| `rl/train.py` | обучение MaskablePPO, экспорт весов, `train_info.json` с seed и SHA-256 |
| `rl/evaluate.py` | проверка на новых seed 100–114: random, nearest, формула v1/v2, агент |
| `rl/check_reward.py` | проверка функции награды до обучения |
| `rl/kaggle/` | ноутбук для обучения на Kaggle |

Порядок:
```bash
pip install -r rl/requirements.txt
python rl/check_reward.py                              # 1. проверить свою награду
python rl/train.py --steps 3000000 --envs 4 --seed 7   # 2. обучить (или ноутбук rl/kaggle на Kaggle)
python rl/evaluate.py --policy rl/out/agent_policy.npz # 3. сравнить с формулами
cp rl/out/agent_policy.npz app/agent/                  # 4. подключить к программе
```

Формула v2 (`rl/formula_v2.json`, 80 попыток Optuna, обучающие seed 0–3) на новых seed 100–114,
ошибка прогноза ±12 ч (`rl/eval_formula.json`):

| Поток, конт./ч | Перестановок на выдачу, v1 → v2 | Отказов, v1 → v2 |
|---|---|---|
| 0,6 | 0,139 → 0,088 | 0,1 % → 0,0 % |
| 0,75 | 0,308 → 0,256 | 3,8 % → 1,3 % |
| 0,9 | 0,350 → 0,351 | 13,3 % → 8,6 % |
